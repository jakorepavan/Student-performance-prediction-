E-Commerce Customer Intelligence and Recommendation System

Project Overview

This project focuses on developing a Machine Learning based product recommendation system for an e-commerce platform.

The system uses the Brazilian E-Commerce Public Dataset by Olist to process product information and generate Top-N product recommendations based on product-category similarity.

Methodology

Main Objectives

- Preprocess and clean product data
- Create product-category features
- Apply TF-IDF vectorization
- Calculate product similarity
- Generate Top-N product recommendations
- Evaluate recommendation output
